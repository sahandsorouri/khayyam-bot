# Khayyam Bot

> A Telegram bot that sends one Khayyam quatrain (rubai) every day.

Live: [@RubaiyatKhayyamBot](https://t.me/RubaiyatKhayyamBot)

## What it does

Each day the bot posts one rubai from Omar Khayyam. Poems are stored locally and served on a schedule.

## Stack

`Python` `python-telegram-bot` `SQLite` `Docker`

## Run

Set `TELEGRAM_BOT_TOKEN` in the environment, then:

```bash
docker compose up --build
```
